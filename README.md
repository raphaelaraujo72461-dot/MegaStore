# Sistema de Busca Otimizado para Catálogo de Produtos - MegaStore


DESCRIÇÃO :
Este projeto consiste em um sistema de alta performance para indexação, busca e recomendação de produtos, desenvolvido como solução para o desafio da **MegaStore**. A aplicação foi construída utilizando a linguagem de programação **Rust**, priorizando eficiência de tempo, segurança de memória e escalabilidade.

---

## Tecnologias Utilizadas

* **Linguagem:** Rust (Edição 2021)
* **Biblioteca Padrão (`std`):** Uso estratégico de estruturas de coleções nativas para otimização de performance sem dependências externas desnecessárias.
* **Gerenciador de Pacotes e Testes:** Cargo



## Como Executar o Sistema

### Pré-requisitos
Certifique-se de ter o compilador do Rust instalado em sua máquina (`rustc` e `cargo`).

### Executando a Aplicação (Simulação)
Para rodar a simulação do sistema da MegaStore com inserções, buscas e recomendações, execute o comando abaixo no terminal:
```bash
cargo run
